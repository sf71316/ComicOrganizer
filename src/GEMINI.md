# ComicOrganize 專案概觀

這是一個用於自動化整理漫畫、圖集資料夾的工具專案。目前核心邏輯基於 PowerShell 實作，正計畫轉型為 C# 視覺化應用程式並優化核心算法。

## 專案結構

- `script/`
  - `圖片整理.ps1`: 核心功能腳本，包含封面重命名、封面提取及自動歸檔邏輯。

## 核心功能說明

### 1. 封面管理
- **命名統一**：將子目錄中的圖檔統一命名為 `cover.ext`。
- **封面提取**：從子目錄或壓縮檔（Zip/Rar/7z）中自動提取第一張圖片作為目錄封面。

### 2. 未整理檔案歸檔
- 掃描特定目錄，透過標題中的 `[關鍵字]` 自動匹配目標庫路徑並移動檔案。

## 開發方向與路線圖 (Roadmap)

### 1. C# 視覺化應用程式轉型
- **目標**：取代目前的命令列互動，提供直觀的 GUI 介面。
- **關鍵組件**：
  - 視覺化路徑配置器（支援瀏覽目錄）。
  - 歸檔預覽清單：在實際移動前，視覺化呈現「來源 -> 目標」的匹配結果，並允許手動修正。
  - 多執行緒處理：確保大型資料庫掃描時介面不卡頓。

### 2. 歸檔功能優化
- **智慧匹配**：
  - 引入模糊匹配演算法（如 Levenshtein Distance），提高關鍵字辨識率。
  - 支援多規則提取：除了 `[]`，可自定義正規表達式來識別作者或系列名。
- **衝突處理**：當一個檔案符合多個目標目錄時，提供選擇介面。
- **操作安全**：增加復原（Undo）功能記錄，或在移動前執行空間檢查。

## 使用與配置 (Legacy PowerShell)

### 執行方式
```powershell
.\script\圖片整理.ps1
```

### 關鍵配置
- `$UnorganizedDirectory`: 來源路徑。
- `$RootDirectory`: 目標庫路徑。
- `$Debug`: 設為 `$true` 可進行模擬測試。
